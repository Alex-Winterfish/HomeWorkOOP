## Классы Product, Category, Smartphone, Lawnrgass
В модуле продукт написаны классы Product и Category.

Класс Product принимает описание единицы товар. Имеет следующие атрибуты:

- name - название товара
- description - описание товара
- price - стоимость товара
- quantity - количество единиц товара
- 
Класс Category принимает описание группы товаров. Имеет следующие атрибуты:

- name - название товара
- description - описание товара
- products - список товаров
- category_count - подсчитывает число категорий товара при каждой инициализации экземпляра класса
- product_count - подсчитывает число товаров в категории
Исключена возможность добавления в категорию товаров классов отличных от Product и его наследников

Класс Smartphone, класс наследник Product. Имеет следующие атрибуты:

- name - название товара
- description - описание товара
- price - стоимость товара
- quantity - количество единиц товара
- efficiency - производительность
- model - модель
- memory - память
- color - цвет
Добавлена функциональность, которая не позволяет складывать товары разных категорий

Класс Lawngrass, класс наследник Product. Имеет следующие атрибуты:
- name - название товара
- description - описание товара
- price - стоимость товара
- country - страна производитель
- germination_period - срок прорастания
- color - цвет
Добавлена функциональность, которая не позволяет складывать товары разных категорий
